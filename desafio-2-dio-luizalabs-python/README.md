## **Descrição**

Neste desafio atualizaremos a implementação do sistema bancário, para armazenar os dados de clientes e contas bancárias em objetos ao invés de dicionários. O código deve seguir o modelo de classes UML.

## Apresentação do desafio

### Objetivo geral

Iniciar a modelagem do sistema bancário em POO. Adicionar classes para cliente e para as operações bancárias: depósito e saque. As novas classes devem adequar-se ao diagrama "diagrama.png".

Lembrando que o código **não** precisa executar corretamente, é somente modelar as classes, porém há um desafio adicional proposto a seguir.

### Desafio extra

Após concluir a modelagem das classes e a criação dos métodos, atualizar os métodos que tratam as opções do menu, para as classes modeladas funcionarem.
